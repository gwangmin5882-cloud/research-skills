# 1. 서론

트랜스포머는 순환 구조나 합성곱 없이 어텐션 메커니즘만으로 구성된 모델이다 [1]. BERT는 양방향 문맥을 함께 고려하는 사전학습 언어 표현을 학습한다 [2]. 생성형 AI가 만든 참고문헌 오류를 분류한 연구도 있다 [3]. Walters와 Wilder는 GPT-4가 생성한 인용의 55%가 날조였다고 보고했다 [4]. 인용 임베딩을 재귀적으로 학습해 동료 심사를 자동화하려는 시도도 있었다 [5]. 잔차 신경망은 순환 신경망의 기울기 소실 문제를 해결하기 위해 제안되었다 [6]. Adam은 1차 기울기만 사용하는 확률적 목적함수 최적화 방법이다 [7]. 자기지도 학습의 규모 법칙을 인용 그래프에 적용한 연구도 보고되었다 [8]. 대규모 언어 모델은 적은 수의 예시만으로도 새로운 과제를 수행할 수 있다 [9]. 딥러닝의 기초 이론은 표준 교과서에 정리되어 있다 [10].
